# צפייה במצלמות – אפליקציית אנדרואיד ל-NVR

שידור חי, תצוגה של כמה מצלמות במסך אחד, צפייה בהקלטות, צילום מסך, הקלטה לטלפון, ומעבר בין HD ל-SD.
האפליקציה עובדת ישירות מול ה-NVR דרך RTSP (מנוע VLC), בלי ענן ובלי שרת ביניים.

## איך מקבלים APK (בלי להתקין כלום על המחשב)
1. פותחים חשבון חינמי ב-github.com, ויוצרים Repository חדש (למשל `nvr-viewer`).
2. מעלים אליו את כל תוכן התיקייה (Add file → Upload files). חשוב לא לשכוח את התיקייה `.github`.
3. בלשונית **Actions** הבנייה רצה אוטומטית (כ-5 דקות). בסיום נכנסים לריצה ומורידים את **NvrViewer-apk**.
4. מחלצים את ה-ZIP ומתקינים את `app-debug.apk` בטלפון (צריך לאשר "התקנה ממקורות לא ידועים").

אפשרות אחרת: לפתוח את התיקייה ב-Android Studio ולבחור Run.

## הגדרה ראשונה
- **כתובת**: ה-IP של ה-NVR. אפשר למצוא אותה בתפריט הרשת של ה-NVR או ברשימת המכשירים בראוטר.
- **פורט RTSP**: בדרך כלל 554.
- **משתמש וסיסמה**: אלה שבהם נכנסים ל-NVR (לרוב admin).
- **יצרן**: אם אתה לא יודע, לוחצים על "זהה יצרן אוטומטית". האפליקציה תנסה את הפורמטים הנפוצים.
- ודא שבהגדרות ה-NVR האפשרות RTSP מופעלת (Network → Advanced / RTSP).
  ב-Hikvision יש לפעמים להגדיר "RTSP Authentication" ל-digest/basic.

## צפייה מחוץ לבית
יש שתי דרכים:
1. **VPN (הדרך המומלצת והבטוחה)**: מתקינים WireGuard או Tailscale בבית (על הראוטר, על מחשב שנשאר דלוק, או על Raspberry Pi). כשהטלפון מחובר ל-VPN, עובדים עם הכתובת המקומית בדיוק כמו בבית.
2. **פתיחת פורט בראוטר**: מפנים פורט 554 (או פורט חיצוני אחר, למשל 8554) אל ה-IP של ה-NVR, ומגדירים DDNS אם ה-IP החיצוני משתנה.
   ⚠️ זה חושף את ה-NVR לאינטרנט. אם בוחרים בדרך הזו, חובה סיסמה חזקה וקושחה מעודכנת.

## טיפים
- במסך הראשי (גריד) האפליקציה משתמשת בזרם המשני (SD) כדי לחסוך בגלישה. לחיצה על מצלמה פותחת אותה במסך מלא ב-HD.
- בגלישה סלולרית כדאי לעבור ל-SD עם כפתור HD/SD.
- **צפייה בהקלטות** נתמכת ב-Hikvision, Dahua ו-Uniview. ב-Reolink ובמכשירים אחרים צופים בהקלטות דרך האפליקציה של היצרן.
- אם השעה בהקלטה לא מתאימה (הפרש של שעתיים או שלוש), כנראה שאזור הזמן מוגדר אחרת ב-NVR. בודקים את הגדרות התאריך והשעה ב-NVR.
- צילומי מסך נשמרים ב-`Pictures/NVR`, והקלטות נשמרות ב-`Movies/NVR` (קובץ ‎.ts, שמתנגן ב-VLC ובגלריה).

## כתובות RTSP לפי יצרן (לבדיקה ידנית ב-VLC)
| יצרן | שידור חי (ערוץ 1) |
|---|---|
| Hikvision | `rtsp://user:pass@IP:554/Streaming/Channels/101` (ו-102 לזרם המשני) |
| Dahua | `rtsp://user:pass@IP:554/cam/realmonitor?channel=1&subtype=0` |
| Uniview | `rtsp://user:pass@IP:554/unicast/c1/s0/live` |
| Reolink | `rtsp://user:pass@IP:554/h264Preview_01_main` |
