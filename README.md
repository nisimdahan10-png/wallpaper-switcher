# מחליף רקעים (WallpaperSwitcher)

אפליקציית אנדרואיד שמחליפה את הרקע בכל פעם שהמסך נכבה או נדלק.

## איך זה עובד
- בוחרים כמה תמונות מהגלריה (אפשר להוסיף עוד בכל שלב).
- בוחרים מתי להחליף: בכיבוי מסך (מומלץ), בהדלקה, או גם וגם.
- בוחרים איפה: מסך בית, מסך נעילה, או שניהם.
- סדר רציף או אקראי.
- מדליקים את המתג. תופיע התראה קבועה ושקטה – היא נדרשת כדי שאנדרואיד יאפשר להאזין לכיבוי/הדלקת המסך.
- אחרי הפעלה מחדש של הטלפון השירות חוזר לפעול לבד.

## בנייה
**Android Studio:** File → Open → לבחור את התיקייה → Run.

**בלי מחשב (GitHub):** להעלות את התיקייה לריפו חדש ב-GitHub.
הבנייה תרוץ אוטומטית בלשונית Actions, וה-APK יופיע תחת Artifacts בשם `app-debug`.

## טיפים
- בשיאומי / סמסונג / וואווי: לאשר "ללא הגבלת סוללה" ו"הפעלה אוטומטית" לאפליקציה, אחרת המערכת עלולה לעצור את השירות.
- בכפתור "החלף עכשיו" אפשר לבדוק שהתמונות נטענות כמו שצריך.
